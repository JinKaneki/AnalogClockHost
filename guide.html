🎛️ Interaction Protocols

  • Mirror Mode – Minimalist full-screen display for any clock mode. Hides all UI elements except the active clock and the Tao Te Ching widget, adding a large empty space under the clock for pure aesthetic contemplation.
  • Stealth Controls – Double-click the background (avoiding any UI element) to freeze/unfreeze immediately with a Ghost UI indicator. The same effect is triggered by pressing the B key.
  • Hide Controls Toggle – A dedicated button in the top-left corner hides/shows all control buttons – FREEZE MOMENT, BG: SYNCED / INDEPENDENT, STYLE, CLEAN VIEW, and the volume slider. When hidden, the buttons remain in the layout (space is preserved) so there's no layout shift.
  • Mechanical Sound Engine – Web Audio API generated ticks/tocks with adjustable volume and instant mute. The sound provides satisfying auditory feedback for every clock tick, button press, and state change.
  • Cycle Clock Styles – Use the STYLE button to cycle through all six clock modes: Classic → Glass → Digital → Cistercian → Cosmic → Celestial.

Engineering & Architecture

EliteGDX isn't just a pretty interface; it demonstrates that even a simple utility like a clock can be elevated through high-level engineering and browser-specific APIs.

🏗️ Software Architecture

  • Frontend Core: Built entirely with pure vanilla HTML5, CSS3, and JavaScript, strictly eliminating the need for bulky external package managers.
  • Static Deployment: Employs optimised file routing and relative pathing configured specifically for seamless, high-performance static hosting on GitHub Pages.
  • Screen Wake Lock API: Prevents device dimming or sleep mode while the tab is active, automatically re-acquiring the lock if you switch away and return.
  • Deterministic State Management: UI transitions are synchronised precisely at 00 seconds of every minute, respecting the "Minute Reset" rule regardless of page load timing.
  • Router-Pattern Command Parser: Executes sync commands instantly, async commands with loading indicators. CORS-aware APIs use rss2json proxy for RSS feeds and direct fetch for CORS-enabled services.
  • PWA Support: Manifest and service worker (sw.js) enable offline caching and installable app behaviour.

🧮 Systems & Simulation

  • Ephemeris Physics Engine: Calculates true planetary positions using self-hosted mathematical ephemeris data and J2000 orbital equations to power the live Mazzaroth Wheel.
  • Fisher-Yates Shuffle: Gallery content is randomised with mathematical perfection, ensuring all items are shown exactly once before the deck is reshuffled.
  • Engineering Case Simulator: The case command acts as a field toolkit, calculating LED resistance stress tests, decoding resistor bands, and solving Ohm's law with live failure warnings.
  • Cistercian Numeral Engine: Implements the medieval monk numeral system (0-9999) using the cistercian-numerals Web Components library, with custom rainbow styling.
  • Neural Graph Overlay: The graph command toggles a live Obsidian-style command-co-occurrence visualisation, mapping the relationships between every command you type in real-time.

🎨 Customisation & Theming

  • Color Themes – Choose from Cyan Night, Magenta Dream, Amber Glow, or Matrix Green. Your preference is saved in localStorage and persists across sessions.
  • Typewriter Effect – Terminal-style name-plate with custom typing/deletion speeds.

Diagnostics & FAQ

Frequently Asked Questions

Q: How do I completely reset my dashboard preferences?

A: Open the terminal and execute the command nuke. This wipes local storage, clears cached states, and reinitialises the UI.

Q: Why does the Moon position differ slightly from simple calendar apps?

A: EliteGDX calculates true astronomical orbital physics using J2000 equations rather than static rounded dates. The fetch command can refresh ephemeris feeds if needed.

Q: How do updates reach ambient/always-on screens?

A: Simply trigger a browser refresh. The Service Worker automatically updates assets in the background on launch.

Q: How do I freeze the background?

A: Double-tap the background (avoiding any UI element) or press B. A ghost indicator 👻 MESSAGE will appear for confirmation.

Q: What's the difference between "Synced" and "Independent" background modes?

A: Synced mode mirrors the central gallery image. Independent mode cycles backgrounds on its own 30-second timer, separate from the minute clock.
