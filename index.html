Project Intent

This dashboard is designed as a Persistent Ambient Display & Interactive Shell. The goal is to bridge the gap between a functional cyberpunk-themed timepiece,live media feeds, and retro telemetry, serving as an "Always-On" companion terminal for a professional workspace.

Technical Architecture

  • Zero-Dependency Vanilla Stack: Built entirely using native HTML5, CSS3, and pure Vanilla JavaScript. This ensures a lightweight footprint, instantaneous load times, and flawless performance on low-power secondary displays without NPM package overhead.
  • Interactive CLI Terminal Shell: A custom-built, in-browser terminal emulator that parses keyboard inputs and commands, allowing real-time state manipulation, Canvas swaps, and slideshow controller overrides directly from a simulated command line.
  • HLS Stream & IPTV Pipeline: Integrates live video streams using `hls.js` with structured channel parsing from custom JSON files. Features robust error-handling, such as a 10-second timeout recovery system to handle stream drops elegantly in an ambient setting.
  • HTML5 Canvas Telemetry Engine: A performance-optimized canvas engine that renders complex real-time animations, including a simulated NetOrbit global network visualizer, using pure mathematical drawing loops to minimize CPU overhead.
  • Screen Wake Lock API: Prevents the host device from entering sleep mode or dimming the display, ensuring the clock and terminal feeds remain fully active during long work sessions.
  • Fisher-Yates Shuffle: An $O(n)$ complexity algorithm used to ensure an unbiased, non-repeating random sequence for the ambient background rotations.
  • Deterministic Minute-Reset: State-management logic that synchronizes UI transitions precisely with the 00-second mark of the system clock.
  • Stealth Gesture & Ghost UI: Implements double-click event listeners and global keyboard hotkeys to toggle diagnostic logs and interface states cleanly, leaving the screen completely free of persistent UI clutter.
  • Unified Astrolabe Engine: A dual-layer canvas system that overlays a DPIscaled cosmic Mazzaroth wheel onto a flat-earth azimuthal projection. Both layers share a single UTC time source, providing a seamless celestial dashboard.
  • DPI-Aware Canvas Rendering: All canvas elements now scale with devicePixelRatio, ensuring razor-sharp symbols, lines, and text on Retina and high-DPI displays.
  • Three-State Clean View & Mirror Mode: A clean view cycle (text off,images off and full clean) hides all UI clutter, while Mirror Mode offers a distraction-free, full-screen meditative experience.
  • Interactive Cosmic Toggles: Show/hide zodiac signs, planets, AC/MC lines, and a glass analog clock on the cosmic wheel, all in real time.
  • Hyper-Speed Simulation: Time multipliers now scale up to 36000x, allowing rapid navigation through celestial cycles.
  • Stretched Flat Earth Projection: An elliptical version of the azimuthal map complements the circular view, giving a wider perspective on the celestial sphere.
